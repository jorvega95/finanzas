# Finanzas

Plataforma de finanzas personales multi-tenant: gastos, TDC con ciclos y MSI, inversiones (crypto vía CoinGecko), presupuestos y dashboard.

- `backend/` — FastAPI + SQLAlchemy async + Supabase (Postgres + Auth)
- `frontend/` — React + TypeScript + Vite + Tailwind

Convenciones, comandos y flujo de trabajo: ver `CLAUDE.md`.
Documentación de diseño (`PLAN.md`, `REGLAS_NEGOCIO.md`): local, no versionada.
